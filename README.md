# Apps Android : FacturePro et RépondAvis

Chaque push sur `main` lance la compilation. Les APK se téléchargent dans l'onglet **Actions**,
puis le dernier run, rubrique **Artifacts**.

Note : l'APK « release » produit ici est signé avec la clé de debug d'Expo, suffisant pour
installer sur ton téléphone. Pour Google Play, il faudra une clé de signature à toi (ou EAS Build).
